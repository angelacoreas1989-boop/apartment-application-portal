## 🏡 Project Overview

Magnolia Grove Apartments is a luxury apartment leasing portal designed to simulate a real-world apartment community website and rental application process.

Prospective residents can browse available apartment homes, explore community amenities, review screening requirements, and complete a multi-section rental application.

The project combines marketing website design with practical application workflow functionality to create a realistic leasing experience.

## 🐾 Pet Friendly Community

Magnolia Grove welcomes pets with:

* Up to 3 pets per apartment
* No breed restrictions
* No weight restrictions
* No monthly pet rent
* Pet Spa
* Bark Park
* ESA accommodations
* Online pet profile registration

### Pet Fees

* First Pet: $400 Non-Refundable Fee
* Second Pet: $250 Non-Refundable Fee
* Third Pet: $250 Non-Refundable Fee

### Pet Requirements

* Pets must be listed on the lease
* Current vaccination records required
* Pet owners must clean up after their pets
* Community pet rules apply
* Pets may be off leash only in designated Bark Park areas
